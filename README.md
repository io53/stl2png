# stl2png

A tiny STL thumbnailer with no runtime dependencies beyond libc. Renders `.stl`
files to PNG on the CPU — no GPU, no OpenGL, no X11 or Wayland required.

<p align="center">
  <img src="docs/gear.png" width="256" alt="stl2png rendering of examples/gear.stl">
</p>

```
$ stl2png -s 256 examples/gear.stl gear.png
```

(`examples/gear.stl` is generated by `python3 examples/make_gear.py`, run from the
repo root — plain Python, no dependencies.)

## Why

Thunar shows thumbnails for any file type that has a registered thumbnailer. For
STL the existing options each come with a trade-off:

| Tool | Trade-off |
|------|-----------|
| [stl-thumb](https://github.com/unlimitedbacon/stl-thumb) | Renders through OpenGL in a hidden window, so it needs a working GL context and display server. On my machine (stl-thumb 0.5.0, Mesa 26, Hyprland, Intel Arc) it produced blank images. |
| [f3d](https://f3d.app) | Excellent viewer and thumbnailer, but depends on VTK — the Arch package pulls in 65 packages / 1.7 GB. |
| Python scripts (numpy-stl + matplotlib) | Seconds per file and a scientific Python stack. |

`stl2png` is a single ~430 KB binary with a software rasterizer. It works
headless, in containers, on a NAS, or on a laptop whose GPU driver had a bad day.
A 4 MB binary STL (84k triangles) renders at 256 px in about 50 ms on a recent
laptop CPU; 1024 px takes about 5× longer.

## Features

- Binary and ASCII STL
- Normals computed from geometry — files with missing or wrong normals still shade correctly
- Fixed three-quarter view, auto-fitted to the model's bounding box
- Flat Lambert shading, 2× supersampled, transparent background
- Output size selectable (`-s`), matching the freedesktop thumbnailer `%s` convention
- One direct dependency (`png`), builds in seconds

## Install

Requires Rust 1.78 or newer.

```sh
git clone https://github.com/io53/stl2png
cd stl2png
cargo build --release
sudo install -Dm755 target/release/stl2png /usr/local/bin/stl2png
sudo install -Dm644 stl2png.thumbnailer /usr/share/thumbnailers/stl2png.thumbnailer
pkill tumblerd
```

That's it. Thunar's thumbnail service (Tumbler) picks up the new `.thumbnailer`
file when it next starts, which is what the `pkill` is for.

If STL files still show the generic icon, Tumbler may have cached an earlier
failure. Clear the cache and reopen the folder:

```sh
rm -rf ~/.cache/thumbnails
```

Tested on Thunar. Other file managers are untested.

To run the test suite (unit tests for the parser and rasterizer, plus end-to-end
tests of the binary):

```sh
cargo test
```

## Usage

```
stl2png [-s SIZE] input.stl output.png
```

| Option | Default | Description |
|--------|---------|-------------|
| `-s`, `--size` | `256` | Output width and height in pixels (1–4096) |
| `-h`, `--help` | | Show usage |
| `-V`, `--version` | | Show version |

Exit status is `0` on success, `1` if the input could not be parsed or the output
could not be written, `2` on bad arguments. A model with no renderable geometry
(all-degenerate or non-finite triangles) is an error, so the file manager falls back
to the generic icon instead of caching an empty image.

## How it works

1. Parse the STL — binary if the header's triangle count fits the file size and the
   file doesn't start with `solid`, otherwise ASCII. Triangles with non-finite
   coordinates are dropped.
2. Rotate into view space (three-quarter view, 30° elevation), fit the bounding box to the frame.
3. Rasterize each triangle with a z-buffer at 2× resolution. Shade by the angle between
   the face normal and a fixed light; normals that face away from the camera are flipped
   so inside-out meshes still look right.
4. Downsample to the target size, using coverage as alpha.
5. Encode as RGBA PNG.

The whole thing is one file, [`src/main.rs`](src/main.rs). Colour, camera angle and
light direction are constants near the top of the render section if you want a
different look.

## Non-goals

- Not a viewer. For rotating a model interactively use [fstl](https://github.com/fstl-app/fstl)
  (tiny, Qt) or [f3d](https://f3d.app).
- Not a general 3D format converter.
